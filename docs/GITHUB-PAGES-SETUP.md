# Sandbox-Lab publication options

## Intended host

The intended Sandbox Lab address remains lab.xn--vofit-mqa.de (IDN: lab.voßfit.de) on the existing Spaceship hosting. No new domain is needed.

## GitHub Pages

GitHub Pages is **not configured or published** and is not the intended live Sandbox host. Do not enable it as a side effect of repository setup. If a separate public preview is ever requested, it must be approved explicitly and reviewed for secrets/private data first.

## Repository

The intended repository is a new **private** GitHub repository named VoßFit-Sandbox. The current local origin still points to the unrelated public, empty nicovoss01/VossBot-Lab; do not push there. The remote can be changed only after the intended private repository exists and its identity/visibility are verified.

## No automatic deployment

No workflow in this repository deploys to GitHub Pages, Cloudflare, or Spaceship. A commit or pull request is development history only, not a live release.
